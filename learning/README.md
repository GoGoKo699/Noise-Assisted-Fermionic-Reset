# Learn the reset mechanism

A uniform chain can transport an ordinary wave packet quickly and still reset slowly, because an unknown input may occupy a coherent mode with very little amplitude at the only sink. Weak independent phase noise removes this protection. Understanding the result means connecting that transport mechanism to a guarantee for the entire register and every external reference.

The single educational anchor is **Rivas and Huelga, Open Quantum Systems: An Introduction (2012)**, using [arXiv:1104.5242v2, 9 February 2012](https://arxiv.org/abs/1104.5242v2). The bridge gives verified section locators, translates notation, and supplies the project-specific derivations beyond the source.
